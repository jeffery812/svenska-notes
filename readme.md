# Svenska Notes

瑞典语学习与速查手册。

这个项目用于记录学习瑞典语时遇到的词汇、表达和语法规则，将零散知识整理成便于查阅的笔记。内容会随着学习逐步补充，重点关注日常用法、容易出错的地方，以及相近表达之间的区别。

## 建议学习顺序

1. **先能开口交流**：学习字母与基础发音、问候、自我介绍，以及请求重复和放慢语速的表达。
2. **能说简单句**：掌握人称代词、常用动词现在时、主句语序、提问与否定；学习名词时一并记住 en / ett。
3. **能应对日常生活**：补充数字、时间、金额与数量，并结合购物、交通和点餐等场景练习。
4. **逐步说得更完整**：学习名词和形容词变化、过去时与完成时、介词、连接词及基本从句。
5. **持续巩固**：通过短文、音频和自己的例句复习，将易混淆词和常见错误加入速查笔记。

各主题不必一次整理完。优先记录当前用得到的内容，再逐步补充规则、变化形式和例外。

## 笔记方式

- 用中文解释规则，保留瑞典语原词和例句。
- 为词汇记录必要的变化形式，例如名词的 en / ett、定形式和复数形式。
- 为动词记录常见变化形式和搭配，避免只记中文意思。
- 为规则配上简短例句与中文释义。
- 区分一般规则、常见例外，以及书面语和口语用法。
- 发音笔记尽量附上可靠的音频链接或音标，避免仅依靠中文谐音。
- 将容易混淆的表达放在一起比较，说明区别。
- 每个主题保留简洁的速查表，并用少量练习检查是否能实际运用。
- 标记尚未确认的内容，核实后再补充；适当记录参考来源。
